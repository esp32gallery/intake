# ESP32 Gallery — public intake

This repository is the public contact surface for [esp32gallery.com](https://esp32gallery.com). It contains no site source code; the site's code is maintained privately.

Use it for three things:

| What | Where |
| --- | --- |
| Submit an ESP32 project | [Open a submission issue](https://github.com/esp32gallery/intake/issues/new?template=project.yml), or use the form on [esp32gallery.com](https://esp32gallery.com) |
| Copyright or media removal | [Open a copyright request](https://github.com/esp32gallery/intake/issues/new?template=copyright.yml) |
| Security vulnerability | [Private vulnerability report](https://github.com/esp32gallery/intake/security/advisories/new) — do not open a public issue |

## What happens to a submission

A submission issue is forwarded to the same review queue the website form uses, and a status comment is posted back on the issue. Review normally finishes in 1–3 days.

Listing a repository means the catalogue cites its public metadata. It does not grant permission to copy project code or media, and a browser preview does not prove board compatibility or physical safety.

## What this repository is not

- Not a mirror of the gallery's code, data, or deployment configuration.
- Not a place for private evidence. Public issues are public; keep identity documents, addresses, contracts, and credentials out of them.
